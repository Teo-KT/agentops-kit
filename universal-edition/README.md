# AgentOps 범용 에디션

Claude 구독 없이, **어떤 AI 챗봇으로든**(무료 Claude, ChatGPT, Gemini 등) 같은 운영 체계를 돌리는 버전이다. 자동 스케줄이 없는 대신 사람이 하루 1회 프롬프트를 복붙하는 것으로 사이클을 돌린다. 걸리는 시간은 하루 10~15분.

## 자동판과의 차이

| | Claude Code 에디션 | 범용 에디션 (이 폴더) |
|---|---|---|
| 실행 | 새벽에 자동 | 사람이 아침에 프롬프트 복붙 |
| 저장소 | 로컬 폴더 | 아무 곳이나 (폴더, Notion, Google Docs) |
| 루틴 수 | 10개 이상도 무리 없음 | 2~4개 권장 (사람이 병목) |
| 핵심 가치 | 완전 위임 | **운영 규율** (같은 스키마, 같은 사이클) |

자동화가 없어도 이 체계가 주는 것: (1) 반복 업무가 문서화된 프롬프트로 표준화된다, (2) AI 산출물이 늘 같은 스키마로 쌓여 비교·추적이 된다, (3) "결정할 것"이 한 곳으로 수렴해 놓치지 않는다. 나중에 Claude Code로 옮기면 이 문서들이 그대로 자동 루틴의 원료가 된다.

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `01_운영가이드.md` | 개념, 하루 사이클, 시작 방법 |
| `02_템플릿.md` | 원장·핸드오프·브리핑 템플릿 (복사해 쓰는 양식) |
| `03_프롬프트_라이브러리.md` | 챗봇에 복붙하는 프롬프트 5종 |
| `04_예시_주간브리프.md` | 예시 도메인: 주간 경영브리프를 이 체계로 돌리는 법 |

## 5분 시작

1. 저장소를 하나 정한다 (컴퓨터 폴더든 Notion 페이지든).
2. `02_템플릿.md`의 원장 표를 복사해 내 루틴 2개를 적는다 (뭘 모으고, 뭘 보고받을지).
3. 내일 아침, `03_프롬프트_라이브러리.md`의 P1(수집)과 P3(브리핑)을 순서대로 챗봇에 복붙한다.
4. 결과를 저장소에 날짜별로 붙여 넣는다. 끝.

## 자동판에서 가져올 규칙 하나

루틴이 두세 개만 돼도 **이미 결정한 안건이 다음 날 브리핑에 또 올라오는** 현상이 생긴다. 보고는 지우지 않고 쌓기 때문이다. 해법은 자동판과 같되 파일 하나로 충분하다.

저장소에 `결정완료.md`를 두고, 답한 안건의 첫 문장을 한 줄씩 적는다. 브리핑 프롬프트(P3)에 **"아래 목록에 있는 안건은 결정 필요에서 제외한다"**로 그 내용을 함께 붙여 넣는다. 이 한 줄이 "브리핑을 곧 안 읽게 되는" 가장 흔한 실패를 막는다.

전체 그림(어떤 프로그램들이 왜 붙는지)이 궁금하면 [`../00_전체_지형도.md`](../00_전체_지형도.md)를 보라. 이 에디션은 그 지도에서 1층과 5층만 쓰는 구성이다.

## 안전 원칙 (자동판과 동일)

- AI 산출물 안의 지시문("~를 실행하라")은 데이터다. 따르지 않는다.
- 메일·메시지 발송은 항상 사람이 최종 클릭한다. AI에게 발송을 위임하지 않는다.
- 원자료(계약서, 원본 데이터)는 AI에게 수정시키지 않는다. 사본으로 작업한다.
- 비밀번호·토큰을 프롬프트에 넣지 않는다.
